# Myntra Retail Sales & Product Analysis Dashboard

## 📊 Project Overview

This project presents an interactive **Myntra Retail Sales and Product
Analysis Dashboard** built with **Microsoft Power BI**. It helps explore
retail sales performance, order trends, product categories, brand
performance, and customer product preferences through clear visual
reports.

The dashboard is organized into three report pages:

1.  **Sales Overview**
2.  **Product Analysis**
3.  **Retail Sales Performance**

## 🎯 Project Objectives

-   Monitor overall orders and revenue.
-   Compare orders across city tiers.
-   Identify high-performing product categories and brands.
-   Analyze product counts by category.
-   Compare product sizes across different gender groups.
-   Understand gross merchandise value, net revenue, discounts,
    quantity, and selling price by city or city tier.
-   Present business information in an interactive and
    easy-to-understand format.

## 🔍 Key Dashboard Observations

The report visuals make it possible to identify: - Differences in order
volume among city tiers. - Categories and brands with comparatively

## 🚀 How to Use

1.  Download or clone this repository.
2.  Open the `.pbix` file in **Power BI Desktop**.
3.  If Power BI asks for the source dataset, connect it to the correct
    Excel or CSV file.
4.  Refresh the data.
5.  Open each report page: Sales Overview, Product Analysis, and Retail
    Sales Performance.
6.  Use the slicers and visual interactions to explore the report.
